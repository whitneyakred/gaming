# Holy Ship v0.2.0 — published checkpoint release

Published November 19, 2026: [release notes and Windows download](https://github.com/whitneyakred/gaming/releases/tag/v0.2.0).

Explore the sea aboard your own ship, or sail with a crew. Steer and adjust the sails, gather supplies, fish, cook, explore islands and work toward Paradise. Browser and desktop co-op are included in the intended demo scope.

Known limits: internet co-op depends on the Harbor service; a service error returns retry guidance. Full use-case extension coverage, sustained classroom performance, and the remaining MVP backlog are not certified by this release. See [traceability](../traceability.md).
