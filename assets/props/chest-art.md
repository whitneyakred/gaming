# Ship chest artwork

Generated with the built-in image generation tool. Transparent PNGs, 1280 × 1280.
The same untrimmed canvas keeps the chest base aligned between states. The game
renders them with nearest filtering at a small sprite scale.

- `ship_chest_closed.png`: closed chest.
- `ship_chest_open.png`: matching opened chest, edited from the closed sprite.

## Closed prompt

Create a game-ready CLOSED wooden ship supply chest sprite, isolated on transparent background. Single chest only, no sheet, no labels. For Holy Ship top-down 2D pixel-art sailing game. Orthographic near top-down RPG perspective: see broad wooden lid and a short front face, horizontally oriented chest, front facing bottom of image, not isometric. Muted desaturated sandy tan oak planks, dusty brown dark outlines, pale beige highlights, subdued dark iron bands and small brass latch. Match hand-pixelled low resolution boat art with visible discrete square pixel clusters, approximately 48x48 logical pixels, no smooth painterly gradients, no tiny photorealistic detail, no glow. Chest base bounding rectangle centered horizontally and occupying x 20%-80%, y 48%-85% of square canvas. Closed lid top at about y 35%, bottom of base at y85%. Leave ample transparent padding above for an opened-lid variant. Clean silhouette, two iron straps running front-to-back, three or four broad lid planks. No treasure or floor. Reference style: pale weathered wooden sailing deck with dark brown single-pixel outlines and restrained 4-tone wood shading.

## Open prompt

Edit this exact closed chest sprite into its OPEN state for a two-state game prop. Preserve the transparent 1280 square canvas, chest base/front face exact pixel position, width, bottom edge, two iron bands, brown outlines, desaturated tan wooden palette, brass latch and pixel-art rendering. Keep the bottom box fixed in place at the same size. Hinge the lid upward toward the top of the image, revealing a dark empty wooden interior, with the raised lid above/behind the box. Base/front at the bottom MUST remain at the exact same x/y position as original to avoid game animation jumping. Lid occupies some of the previously empty transparent space above. No coins, no contents, no other props, no background or text. Keep same orthographic near top-down front-facing perspective and same sprite scale. This is OPEN sprite counterpart, not a new chest design.
